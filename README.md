# 📝 Organizador de Tareas en Python

## 📌 Descripción
Este proyecto es un **organizador de tareas** escrito en Python.  
Permite gestionar tareas de manera sencilla: agregarlas, buscarlas, mostrarlas, cambiar su estado y eliminarlas.  
Las tareas se guardan en un archivo JSON (`tareas.txt`) para mantener la información entre sesiones.

---

## 🚀 Funcionalidades
- ➕ **Agregar tareas** con título, descripción, prioridad y estado.
- 📋 **Mostrar todas las tareas** guardadas.
- 🔍 **Buscar tareas** por título.
- 🔄 **Cambiar el estado** de una tarea (Pendiente, En progreso, Completada).
- ❌ **Eliminar tareas** existentes.
- ⏳ **Mostrar solo las tareas pendientes**.

---
